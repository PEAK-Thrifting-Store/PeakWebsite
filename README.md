# MBM website

A static, GitHub Pages-friendly overview site for MBM. It uses plain HTML, CSS, and vanilla JavaScript, so it does not need a build step or a server.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server if installed.

## Deploy on GitHub Pages

1. Create a GitHub repository and upload these files to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the main branch and the `/ (root)` folder, then save.

The site currently uses image URLs from Unsplash and the public MBM Instagram profile. Replace those URLs with owned brand images when they are available.
